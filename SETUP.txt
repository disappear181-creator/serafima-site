ГОТОВО
Шесть файлов сайта в site/ скопированы без изменения дизайна и содержания.
Сайт работает как обычная статика: сервер приложений и сборка не нужны.
В комплекте — короткая инструкция START_HERE.txt, инструкция для GPT (AGENTS.md),
скрипт публикации и GitHub workflow.
Авторизация хостинга, реальная публикация и доступ из другого Plus ещё не выполнены.

ВАРИАНТ РАЗМЕЩЕНИЯ
GitVerse Pages Free. Бесплатный адрес — поддомен вида
https://<логин>.gitverse.site либо https://<логин>.gitverse.site/<репозиторий>.
Если нужен короткий адрес без пути, логин без точек и название репозитория
должны совпадать. Например serafima-demina → serafima-demina.gitverse.site,
если этот логин свободен. Адрес пока НЕ зарегистрирован.
На текущем этапе GitVerse Pages не поддерживает собственные домены.
Публикуемый репозиторий публичный; клиентские данные и ключи в него не кладут.

ОДНОРАЗОВАЯ НАСТРОЙКА
Следуйте START_HERE.txt. Агент выполняет техническую работу.
1. В уже подключённом GitHub создать serafima-site с README и дать ChatGPT
   доступ к этому репозиторию. Прислать ссылку — агент сам загружает комплект.
2. Создать GitVerse-аккаунт владельца сайта с коротким логином без точек.
3. Сохранить токен в одном GitHub Secret GITVERSE_TOKEN. Права: Пользователь —
   Чтение; Репозиторий — Чтение и Запись. В чат токен не отправлять.
   Bootstrap получает логин и создаёт выделенный публичный репозиторий.
   Обязательные Variables больше не нужны.
4. Агент запускает Publish website to GitVerse. Затем владелец один раз
   включает CI/CD и Pages: Источник Ветка, main, папка /.
5. Проверить реальную публикацию и доступ из РФ. Подключить репозиторий
   к Plus/Codex Серафимы; правки скриншотами применяются после запуска.

ДАЛЬНЕЙШАЯ РАБОТА
Можно писать: «Измени цену онлайн-консультации на 4500 рублей. Сохрани
остальной дизайн, проверь страницу и опубликуй». Codex меняет файлы;
коммит в main запускает публикацию. Кредиты/лимиты Plus применяются к правкам,
но сайт после публикации не зависит от запущенного GPT или включённого ПК.
Другому GitHub-аккаунту нужно явно выдать права на репозиторий. Одна только
подписка Plus не даёт доступа к чужим файлам. Внешнее приглашение в текущий
личный ChatGPT Site даёт просмотр, а не редактирование.

ПЕРЕЕЗД НА ДРУГОЙ ХОСТИНГ
Копировать содержимое site/ в корень другого статического хостинга либо
подключить туда этот GitHub-репозиторий и каталог site/. CI-публикацию GitVerse
можно отключить. HTML/CSS/JS сохраняются. Бесплатный адрес GitVerse нельзя
перенести с собой; постоянный собственный домен покупается отдельно.

ТЕКУЩИЕ ОГРАНИЧЕНИЯ
Реальных фото и дипломов нет, режим согласования сохранён.
Форма готовит текст для самостоятельной отправки; серверного приёма заявок нет.
Условия GitVerse Pages прямо называют лендинги и сайты компаний, но общий
договор содержит широкую формулировку о коммерческой рекламе. Применимость
этого ограничения к сайту платных консультаций лучше уточнить у провайдера
до выбора как постоянной бизнес-площадки; юридическую гарантию не даём.
Бесперебойность из всех стран нельзя обещать. После публикации проверяется
HTTPS и загрузка с российского домашнего/мобильного подключения и извне.
Для полной автономности по сети на сайте нет внешних библиотек/шрифтов;
работа сторонних мессенджеров определяется их доступностью у посетителя.
